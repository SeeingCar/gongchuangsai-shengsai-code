# 工创赛省赛代码

2027 年第十届中国大学生工程实践与创新能力大赛「智能搬运」赛项 —— **省赛固件代码** 与 **场景设置与任务命题文档**。

## 仓库内容

| 路径 | 说明 |
| --- | --- |
| `智能搬运任务命题文档.pdf` | 赛项命题文档(6 页):决赛物料、场地分区、竞赛流程、评分方法 |
| `工创赛省赛代码/` | STM32F407ZGTx 固件工程(Keil MDK / IAR EWARM / CubeMX),含源码、工程文件与交接文档 |
| `工创赛省赛代码/README.md` | 固件工程的目录结构、模块职责、硬件接口、编译方式与通信协议 |

## 快速开始

1. **看文档**:先读 `工创赛省赛代码/规则.md`,需要细节再查 `工创赛省赛代码/交接_给小模型_必读.md`。
2. **编译固件**:Keil MDK 打开 `工创赛省赛代码/MDK-ARM/hard.uvprojx`(目标 `hard`)编译下载;或用 IAR 打开 `工创赛省赛代码/EWARM/Project.eww`。
3. **改外设**:用 STM32CubeMX 打开 `工创赛省赛代码/hard.ioc`。

## 固件概览

- MCU:STM32F407ZGTx(LQFP144),STM32Cube HAL + FreeRTOS(CMSIS-RTOS v2),20 ms 控制节拍
- 两套状态机:底盘 `GroundFloor/`(`TaskFlow_Update`)+ 手臂 `Grab/`(`GRAB_Update`)
- 执行器:四轮 ZDT 闭环步进、GM6020 整臂旋转(CAN)、伸缩/升降步进(USART5)、夹爪与转盘舵机(TIM4 PWM)
- 传感器:HWT601 陀螺仪(Modbus)、相机/扫码(USART3)

## 命题文档要点

- **决赛物料**:双圆台组合结构,PLA 3D 打印,重心居中、四周斜面、小端面接触码垛(第 1 页)
- **场地**:2400 mm × 2400 mm,四周 150 mm 黄色干扰条带;原料区、二维码区、粗加工区、精加工区、成品区(可旋转转盘)、两处 300 mm × 300 mm 启停区(第 2 页)
- **流程**:3 分钟准备;读取五组三位数字的二维码顺序码(如 `546+231+654+213`)并在车载屏展示;双批次搬运,第一批经粗加工区与精加工区,第二批经精加工区后在成品区完成第二层码垛(第 4–5 页)
- **评分**:读码展示 6 分、持续显示 2 分、搬运每块 2 分、平面放置按与色环同心度计分、成品区第二层每块 10 分、返回启停区 4 分(第 5 页)
